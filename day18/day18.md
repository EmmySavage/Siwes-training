HTML is used to build the structure and content of a web page,the head paragraphs buttons navigation bar, bread crumb. 

CSS is used to control how the HTML page looks. It can change colours, sizes, spacing, fonts and the overall layout, transition,position of contents in the html page.

Flask is different because it runs on the server and handles the logic behind the website. It can receive requests from a user, decide what should happen, communicate with a database, and send the appropriate HTML page back to the user's browser.

In simple terms, HTML builds the page, CSS makes the page look good, and Flask controls what happens behind the page.
