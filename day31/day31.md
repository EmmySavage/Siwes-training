Excel Day 1: Worksheet Basics and Basic Formulas
1. Creating a Worksheet
A worksheet is a spreadsheet made up of rows and columns where data can be entered, organised and calculated.
To create one:
Open Microsoft Excel.
Select Blank Workbook.
Start entering data into cells.
Save the workbook using Ctrl + S.
2. Understanding Rows, Columns and Cells
Rows: Run horizontally and are identified by numbers (1, 2, 3…).
Columns: Run vertically and are identified by letters (A, B, C…).
Cells: The intersection of a row and a column.
For example, A1 refers to the cell in column A and row 1.

4. Basic Worksheet Formatting
Formatting improves the appearance and readability of a worksheet.
Some formatting features include:
Bold: Makes text thicker and more visible.
Fill Color: Adds background colour to cells.
Font Color: Changes text colour.
Alignment: Positions text within cells.
Borders: Adds lines around cells.
Currency Formatting: Displays amounts using a currency symbol.
For the business worksheet, the Nigerian Naira (₦) can be used for financial records.
5. Basic Excel Formulas
Excel formulas are expressions used to perform calculations.
A formula generally begins with the equals sign (=).
Addition (+)
Addition is used to calculate the sum of two or more values.
Example:
=15000+8000
Result: 23000
Addition can also be performed using cell references.
If C2 contains 15000 and C3 contains 8000:
=C2+C3
Subtraction (-)
Subtraction is used to find the difference between two values.
Example:
=15000-10000
Result: 5000
Using cell references:
=C2-D2
This formula can calculate the outstanding balance of a customer.
6. Using the SUM Function
SUM is a built-in Excel function used to add multiple values.
Example:
=SUM(7000,3000)
Result: 10000
SUM can also calculate values within a range of cells.
Example:
=SUM(C2:C4)
This adds all numerical values from C2 through C4.
