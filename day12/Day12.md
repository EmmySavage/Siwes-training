Assignment-
If I opened the file in "w" mode a second time, Python would erase the existing contents of the file before writing the new data.
Answer-
This is dangerous because I could accidentally delete information that I wanted to keep. The "a" mode is safer when I want to add new information to an existing file without removing the old information.

"w" → Write → replaces existing content
"r" → Read  → reads existing content
"a" → Append → adds to existing content
