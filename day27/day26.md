Today I compared using raw SQL with sqlite3 and using SQLAlchemy. For me, raw SQL with sqlite3 felt easier to understand at first because I could see the actual SQL commands like CREATE TABLE, INSERT, and SELECT. I could clearly see what was happening in the database.

SQLAlchemy felt a little harder at first because I had to learn things like db.Model, db.Column, and data types such as db.Integer and db.String. However, I can see that SQLAlchemy can make working with databases easier once I understand how it works.

Overall, I found raw SQL easier to understand because it was more straightforward and I could see the database commands directly. SQLAlchemy is still useful, but I need more practice with it before it feels as natural as sqlite3.
